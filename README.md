# sudokuX1
SudokuX is an interactive Sudoku game developed in C that allows users to solve puzzles, enter custom grids, and validate answers. It features automatic solving using backtracking, hints, puzzle statistics, and an interactive mode where players enter answers cell by cell, receive instant feedback, and track their progress.
